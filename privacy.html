Privacy Policy

Last updated: 26 November 2026

This policy describes how Wow Per Second Studio ("the app") handles data. The app is a private tool used only by the owner of the Wow Per Second channel to publish videos to the channel's own TikTok, YouTube and Instagram accounts.

What data the app accesses

  • Account authorization: when the owner connects an account, the platform (TikTok, Google/YouTube or Instagram) gives the app an access token. The app uses it only to publish the owner's videos and read the owner's own basic profile and video statistics (for example follower and view counts).
  • Basic profile information of the connected account (display name, username, avatar) to show which account is connected.
  • Statistics about the channel's own videos, used to decide which kinds of videos to make next.

How data is stored

Tokens and statistics are stored only on the owner's own computer. They are not uploaded to any server operated by Wow Per Second, and they are not shared with, sold to or used by any third party.

Other people's data

The app does not collect data about viewers or other users. It does not read messages, contacts or other accounts.

Deleting data and revoking access

Access can be revoked at any time in each platform's settings (TikTok: Settings → Security → Manage app permissions; Google: myaccount.google.com/permissions; Instagram: Settings → Apps and websites). Revoking access makes the stored token useless; the owner can also delete it from the computer. To ask about your data, email wowpersecond@gmail.com.

Google API Services

Wow Per Second Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Changes

If this policy changes, the new version will be published on this page with a new date.
